Enterprise AI Workflow Automation: Interactive Demo

Submit an employee request and watch the classification, routing, and approval logic run live.
This is a self-contained simulation of the n8n workflow's decision logic (see workflows/employee-request-automation.json for the real importable n8n workflow). It runs entirely in your browser using the same classification rules described in prompts/classification-prompt.md. It does not call a live n8n instance, real Jira, Slack, or Gmail account. This is intentional: it lets the routing and escalation logic be demonstrated reliably without exposing live credentials.
